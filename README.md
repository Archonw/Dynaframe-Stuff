## Dynaframe's Magic Mirror: write or port modules

Dynaframe's Magic Mirror (in the store above) is a MagicMirror²-style scene for DynaFrame. Add-on modules are easy to write, and modules of the original [MagicMirror²](https://github.com/MagicMirrorOrg/MagicMirror) can be rebuilt for it.

- **Guide: [MODULES.md](DynaframPro/Jans-store/plugin_packs/magic-frame/MODULES.md)**. It is complete on its own, so you can hand it to an AI together with the link to a MagicMirror² module and let it do the port.
- Example sources: [module-sources](DynaframPro/Jans-store/plugin_packs/magic-frame/module-sources) (Guest Wi-Fi, WebUntis, Music Assistant, Jellyfin, river level)
